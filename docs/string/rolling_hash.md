## 概要

文字列の多項式ハッシュを前計算し、部分文字列のハッシュを求める。添字は 0 始まり、区間は `[l, r)`。`T` には文字からの構築、加算、減算、乗算が必要。衝突があり得るため、ハッシュの一致だけで文字列の一致は保証されない。

## コンストラクタと操作

```cpp
RollingHash<T> rh(s);
RollingHash<T> rh(s, base);
```
既定の基数は `T(2525)`。構築は時間・空間とも $O(|s|)$。

### `size()`

文字列の長さ

計算量: $O(1)$

### `get()`

全体のハッシュ

計算量: $O(1)$

### `get(l, r)`

`[l, r)` のハッシュ

計算量: $O(1)$

### `shift(h, d)`

ハッシュ `h` に基数の `d` 乗を掛ける

計算量: $O(1)$

`0 <= l <= r <= size()`、`0 <= d <= size()` を前提とする。異なるオブジェクトのハッシュを比較する場合は、同じ `T` と基数を使う。
