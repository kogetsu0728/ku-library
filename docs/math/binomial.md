## 概要
階乗と逆階乗を前計算し、順列・組合せ・重複組合せを求める。`T` には `T(0)`、`T(1)`、乗算、除算が必要。`T(n!)` が可逆であることを前提とする。`StaticModInt<P>` や `DynamicModInt` を素数 `P` で使う場合、`n < P` が必要。

## コンストラクタ
```cpp
Binomial<T> bin(n);
```
- `0` から `n` までの階乗と逆階乗を作成する。`n >= 0`。

### 計算量
逆元の計算を $O(\log M)$、その他の演算を $O(1)$ として、
- $O(n+\log M)$。逆元を定数時間で求められる型なら $O(n)$。

## p
```cpp
T p(int a, int b)
```
順列の総数 ${}_a P_b$ を返す。`b < 0` または `a < b` なら `0`。それ以外は `0 <= a <= n` が必要。
### 計算量
- $O(1)$

## c
```cpp
T c(int a, int b)
```
組み合わせの総数 ${}_a C_b$ を返す。`b < 0` または `a < b` なら `0`。それ以外は `0 <= a <= n` が必要。
### 計算量
- $O(1)$

## h
```cpp
T h(int a, int b)
```
重複組合せの総数 ${}_a H_b$ を返す。`a == b == 0` なら `1`。`a <= 0` または `b < 0` なら `0`。それ以外は `a + b - 1 <= n` が必要。
### 計算量
- $O(1)$
