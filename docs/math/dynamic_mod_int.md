## 概要
実行時に設定する法で整数演算を行う。初期の法は `998244353`。`set_mod(m)` は全インスタンスで共有する法を変更するため、既存の値を使い続ける途中で変更しない。

## 操作
```cpp
DynamicModInt::set_mod(m);
DynamicModInt x(value);
```

| メソッド・演算子 | 内容 |
| --- | --- |
| `mod()` / `val()` | 現在の法 / 正規化された値 |
| `raw(v)` | 正規化せず値を作る。`0 <= v < m` が必要 |
| `+`, `-`, `*`, `/` と各複合代入 | 四則演算 |
| `==`, `!=` | 値の比較 |
| `pow(y)` | `y` 乗 |
| `inv()` | 逆元 |

`0 < m <= INT_MAX / 2` とする。`pow` の指数は非負。`pow` と `inv` と除算は $O(\log m)$ または $O(\log y)$、他は $O(1)$。`inv()` は `x^(m-2)` を使うため、**法が素数で、値が 0 でない**場合に逆元になる。除算も同じ条件が必要。
